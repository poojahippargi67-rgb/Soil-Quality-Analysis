# 🌱 Soil Quality Analysis Using Machine Learning

> A Machine Learning project that analyses soil quality using soil parameters and predicts soil quality with a Random Forest Classifier to support data-driven agricultural decisions.

---

## 📖 Project Overview

Soil quality plays a vital role in agricultural productivity. This project uses Machine Learning to analyse important soil parameters and classify soil quality into different categories. The trained model can help farmers and researchers evaluate soil health and support better crop planning.

---

## 🎯 Objectives

- Analyse soil quality using soil properties.
- Perform data preprocessing and exploratory data analysis.
- Build and train a Machine Learning classification model.
- Predict soil quality based on user-provided soil parameters.
- Evaluate the model's performance using standard evaluation metrics.

The Random Forest algorithm is used because it:

- Provides high prediction accuracy.
- Handles large datasets efficiently.
- Reduces overfitting.
- Performs well on classification problems.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/poojahippargi67-rgb/Soil-Quality-Analysis.git
```

Move to the project directory:

```bash
cd Soil-Quality-Analysis
```

Install the required libraries:

```bash
pip install -r requirements.txt
```
